🍟 麦麦挂件 · 看门狗 + 主动提示 设计预览

解决「麦麦进程是唯一显示通道 → 一挂就静默失败」的问题。两层保活，你基本无感。

📐 它长什么样（架构）

你 / 助手 → push_bubble → 写队列文件 → 麦麦进程（显示气泡）
launchd 开机自启 ↘ 看门狗 watchdog ↺ 每 5s 探活
看门狗盯着麦麦进程：没在跑 → 5 秒内自动 open 拉起。Mac 重启后由 launchd 保活，整条链不断。

🛡️ 两层保活

层 1 看门狗自动自愈：后台常驻，每 5 秒 pgrep 麦麦；挂了就自动拉起 → 你最多空白几秒，基本无感。

层 2 主动提示（兜底）：万一连看门狗都没激活，我每次推气泡前先查「麦麦在跑吗」；没跑就直接告诉你，而不是假装气泡已显示。

👀 你会看到 / 听到什么

场景 1 · 正常
麦麦常驻桌角，气泡照常弹出。
状态文件 ~/.mcd-pet/watchdog.json → {"alive": true, "restarts": 0}
场景 2 · 麦麦崩了 / Mac 重启
看门狗 5 秒内检测到 → 自动 open 拉起 → 你无感。
🔔 通知 「🍟 麦麦已自动重启」（可选，macOS 通知中心弹出）
场景 3 · 看门狗也没起（你还没激活 launchd）
我推气泡前查到麦麦没跑，直接说：
⚠️ 助手 「麦麦没在跑，跟我说『启动麦麦』我立刻拉起它。」（而不是假装已显示）

⚙️ 真·看门狗脚本（约 40 行，已写好待激活）

# watchdog.py —— 每5s探活，挂了自动 open 拉起
import os, time, json, subprocess
APP = "/Users/nina/Applications/麦麦挂件.app"
MARKER = "麦麦-tk.py"
STATUS = os.path.expanduser("~/.mcd-pet/watchdog.json")

def pet_running():
    r = subprocess.run(["pgrep","-f",MARKER], capture_output=True, text=True)
    return bool(r.stdout.strip())

def start_pet():
    subprocess.run(["open", APP], check=False)

def main():
    restarts = 0
    while True:
        if not pet_running():
            restarts += 1
            start_pet()
            subprocess.run(["osascript","-e",
              'display notification "🍟 麦麦已自动重启" with title "麦当劳麦麦挂件"'])
        time.sleep(5)
main()
开机自启靠 launchd：com.mcd.pet.watchdog.plist（KeepAlive + RunAtLoad）也已写好，归系统管，不受 WorkBuddy 开关影响。

🖱️ 你需要做的一件事（一次性）

看门狗要「开机自启」，需在你自己的终端跑一句（WorkBuddy 沙箱没权限动 launchd）：

launchctl load -w ~/Library/LaunchAgents/com.mcd.pet.watchdog.plist
只此一次。之后 Mac 重启、麦麦崩了，都由看门狗自动兜住。

▶️ 要不要做？
